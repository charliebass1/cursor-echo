# Research Data Notes

This folder is for sanitized research artifacts only.

## Okay To Commit

- Sanitized excerpts with names, secrets, company details, and proprietary code removed
- Synthetic examples created for analysis
- Aggregated counts or coded observations
- Public links and public quotes with attribution

## Keep Local Unless Sanitized

- Raw Cursor transcripts
- Private interview notes
- Screenshots containing user, company, repo, or credential details
- Proprietary code snippets
- Any file containing API keys, tokens, customer names, or private business context

## Suggested Local Workflow

Keep raw material outside Git or in an ignored local folder, then copy only cleaned excerpts or summarized signals into this research folder.
